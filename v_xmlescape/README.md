# v_xmlescape

SIMD-accelerated XML text escaping, generated by `v_escape_codegen` using the
shared `v_escape-base` runtime.

## Escaping rules

| Character | Replacement |
| --- | --- |
| `&` | `&amp;` |
| `<` | `&lt;` |
| `>` | `&gt;` |

All other characters, including quotes, apostrophes, slashes, whitespace, and
Unicode, are copied verbatim. Existing entity text is escaped as literal text:
`&amp;` becomes `&amp;amp;`.

Use these functions for XML text content. XML attribute values require their
own rules for the delimiter quote and whitespace. XML character validation and
line-ending normalization belong to the serializer.

## Usage

```rust
use v_xmlescape::{escape_bytes, escape_fmt, escape_string};

let text = "a\"b/c & <tag>";
let expected = "a\"b/c &amp; &lt;tag&gt;";

assert_eq!(escape_fmt(text).to_string(), expected);

let mut output = String::from("prefix: ");
escape_string(text, &mut output);
assert_eq!(output, format!("prefix: {expected}"));

let mut bytes = Vec::new();
escape_bytes(text, &mut bytes);
assert_eq!(bytes, expected.as_bytes());
```

All three APIs use the same escaping rules. `escape_string` and `escape_bytes`
append to the supplied buffer. The runtime selects AVX2/SSE2 on x86_64, NEON on
aarch64, or SIMD128 on wasm32 when available, with a scalar fallback.

## Features

The defaults enable `std`, `string`, `fmt`, and `bytes`.

- `string`: append escaped text to a `String`.
- `fmt`: return a value implementing `Display`.
- `bytes`: append escaped UTF-8 bytes to a `Vec<u8>`.
- `alloc`: allocation support.
- `std`: standard library support and runtime CPU feature detection.

## Regeneration

From the repository root:

```sh
cargo run -p v_escape_codegen -- --input-dir v_xmlescape
cargo fmt --all
```

The mapping lives in `src/_lib.rs`; `src/lib.rs` and `tests/lib.rs` are generated.
The XML contract tests live separately in `tests/xml_text.rs`.
